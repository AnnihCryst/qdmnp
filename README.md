# Скрипты для модели КТ-МНЧ

Этот набор скриптов построен вокруг решателя из
`qd_mnp_rational_fit.py`. В нем поляризуемость металлической
наночастицы аппроксимируется суммой лоренцевых мод, а не полиномом для
`1/alpha(omega)`. Это делает временную задачу устойчивее и ближе к физической
модели связанных диполей.

## Файлы проекта

| Файл | Назначение |
|---|---|
| `qd_mnp_rational_fit.py` | основной модуль рациональной модели |
| `qd_mnp_params.py` | общий модуль переопределения параметров |
| `qd_mnp_linear_spectrum.py` | слабополевые сечения экстинкции, рассеяния и поглощения |
| `qd_mnp_fano_scan.py` | поиск параметров с Фано-провалом |
| `qd_mnp_pulse_absorption_sweep.py` | нелинейный импульсный расчет энергетического и спектрального отклика |
| `qd_mnp_plot_rational_fit_results.py` | восстановление графиков rational-fit расчета из `data.npz` |
| `qd_mnp_plot_pulse_absorption_results.py` | восстановление графиков pulse-sweep расчета из `data.npz` |
| `qd_mnp_legacy_inverse_alpha_absorption.py` | архивная неудачная реализация через `1/alpha(omega)` |

## Связь файлов

`qd_mnp_rational_fit.py` - главный физико-численный модуль. Он задает параметры
по умолчанию, строит поляризуемость МНЧ, подгоняет ее лоренцевыми модами и
решает связанную систему ОДУ для МНЧ и КТ.

`qd_mnp_params.py` - маленький вспомогательный модуль. Он берет параметры по
умолчанию из `qd_mnp_rational_fit.py` и заменяет только те величины,
которые были переданы через аргументы командной строки.

`qd_mnp_linear_spectrum.py` - быстрый линейный расчет без временного импульса.
Он отвечает на вопрос: есть ли в выбранной геометрии и при выбранных параметрах
слабополевой Фано-провал, то есть ситуация, когда связанная система КТ-МНЧ
имеет меньшую экстинкцию, чем голая МНЧ.

`qd_mnp_fano_scan.py` - автоматический перебор параметров линейной модели. Его
удобно использовать, когда нужно подобрать расстройку КТ, ширину линии,
дипольный момент и силу связи так, чтобы около рабочей энергии возник
Фано-провал.

`qd_mnp_pulse_absorption_sweep.py` - основной нелинейный расчет. Он запускает
временную динамику для набора амплитуд и длительностей импульса, считает работу
внешнего поля и эффективные спектральные сечения из Фурье-компоненты диполя.

`qd_mnp_plot_rational_fit_results.py` и
`qd_mnp_plot_pulse_absorption_results.py` - скрипты восстановления графиков.
Они не повторяют тяжелые вычисления, а читают сохраненные `data.npz` и
`params.json` из папки конкретного запуска.

`qd_mnp_legacy_inverse_alpha_absorption.py` - архивная неудачная реализация.
Он относится к попытке решать задачу через полиномиальную аппроксимацию
обратной поляризуемости `1/alpha(omega)` и высокопорядковое уравнение для
диполя МНЧ. Мы оставляем его в репозитории только для истории и сравнения:
такая схема оказалась плохо контролируемой численно, чувствительной к порядку
полинома и менее надежной для расчета поглощения коротких импульсов.

## Установка окружения

Проект использует [uv](https://docs.astral.sh/uv/) для управления зависимостями.
Версии пакетов зафиксированы в `uv.lock`, интерпретатор по умолчанию -
Python 3.14.7 (файл `.python-version`).

Для первичной настройки выполните:

```powershell
.\setup_env.ps1
```

Скрипт проверяет наличие uv (сам он его не устанавливает и не обновляет),
создает окружение `.venv` по `uv.lock`, ставит зависимости и проверяет импорты.
Если uv отсутствует или его версия старее рекомендуемой, скрипт сообщит об этом.

Эквивалентная ручная команда - просто:

```powershell
uv sync
```

После настройки скрипты можно запускать как через `.venv\Scripts\python.exe`,
так и короче, через `uv run <script>.py`.

## Рекомендуемый порядок работы

1. Сначала построить линейный спектр:

```powershell
.\.venv\Scripts\python.exe qd_mnp_linear_spectrum.py --energy-min-ev 2.0 --energy-max-ev 2.08 --target-ev 2.042
```

2. Если около рабочей энергии нет Фано-провала, запустить поиск параметров:

```powershell
.\.venv\Scripts\python.exe qd_mnp_fano_scan.py --gamma-population-mev 3.02 --gamma2-coherence-mev-values 1.51 2.0 2.78 3.02 --top 10
```

Fano scan трактует каждое значение списка как полную ширину когерентности
`Gamma2`. При `gamma1 = 3.02 meV` нижняя физически допустимая граница равна
`gamma1/2 = 1.51 meV`; меньшие значения останавливают расчет до подгонки МНЧ.

3. Проверить найденный кандидат в линейном спектре:

```powershell
.\.venv\Scripts\python.exe qd_mnp_linear_spectrum.py --energy-min-ev 2.02 --energy-max-ev 2.07 --omega0-ev 2.0235 --gamma2-coherence-mev 2.78 --gamma-population-mev 3.02 --d-debye 30 --G 20
```

4. Только после этого запускать нелинейную импульсную серию:

```powershell
.\.venv\Scripts\python.exe qd_mnp_pulse_absorption_sweep.py --x-axis fluence --omega0-ev 2.0235 --gamma2-coherence-mev 2.78 --gamma-population-mev 3.02 --d-debye 30 --G 20
```

В этих примерах `2.78 meV = 3.02/2 + 1.27 meV`: параметр командной строки
задает полную скорость затухания когерентности `Gamma2`, а не только чистую
дефазировку. Ядро требует `Gamma2 >= gamma1/2`.

## Сохранение и восстановление результатов

Долгие расчеты теперь сохраняют полные результаты в папку запуска `run-dir`.
Если `--run-dir` не указан, создается папка с текущим временем:

```text
results/rational_fit_runs/YYYYMMDD_HHMMSS
results/pulse_absorption_sweeps/YYYYMMDD_HHMMSS
```

В каждой такой папке есть:

```text
data.npz       вычислимые массивы
params.json    фактически использованные физические и численные параметры
*.png          графики, построенные при расчете
```

Новые расчеты имеют `schema_version = 2`. Их нельзя смешивать с прежними
артефактами schema 1: изменилась нормировка intensity/fluence при
`eps_m != 1`, а штатное расстояние `R` увеличено с 16 до 18 nm для устранения
перекрытия 4-нм КТ с МНЧ. Старые NPZ по-прежнему читаются plotter-скриптом.

Для `qd_mnp_rational_fit.py` сохраняются массивы аппроксимации
`alpha(omega)`/`1/alpha(omega)` и временная динамика одного импульса:

```powershell
.\.venv\Scripts\python.exe qd_mnp_rational_fit.py --run-dir results/my_rational_run --modes 1 2 3 4 --pulse-e0-v-m 2.5e5 --tau-fs 5 --no-show
```

Восстановить графики без повторного расчета:

```powershell
.\.venv\Scripts\python.exe qd_mnp_plot_rational_fit_results.py --run-dir results/my_rational_run --no-show
```

Для `qd_mnp_pulse_absorption_sweep.py` сохраняются итоговые матрицы сечений и
полные временные траектории для каждой точки сетки:

```powershell
.\.venv\Scripts\python.exe qd_mnp_pulse_absorption_sweep.py --run-dir results/my_pulse_run --tau-fs 5 10 25 --points 50 --x-axis fluence --no-show
```

Восстановить общий график сечений:

```powershell
.\.venv\Scripts\python.exe qd_mnp_plot_pulse_absorption_results.py --run-dir results/my_pulse_run --no-show
```

Восстановить временную динамику отдельной точки sweep:

```powershell
.\.venv\Scripts\python.exe qd_mnp_plot_pulse_absorption_results.py --run-dir results/my_pulse_run --trace-index 0 --no-show
```

## Что считается в импульсном скрипте

`qd_mnp_pulse_absorption_sweep.py` выводит две группы величин.

`sigma_energy_transfer_cm2` - интегральная работа внешнего поля, нормированная
на fluence:

```text
sigma_E = W_ext / fluence
```

Здесь `W_ext = integral E_inc(t) d(mu_total)/dt dt`. Это энергия, изъятая из
падающего поля, но не автоматически чистое материальное поглощение: в нее также
может входить излученная энергия.

`sigma_spectral_ext_cm2`, `sigma_spectral_sca_cm2` и
`sigma_spectral_abs_cm2` - эффективные спектральные сечения на частоте лазера:

```text
sigma_ext(omega_L) = k / epsilon0 * Im alpha(omega_L)
sigma_abs(omega_L) = sigma_ext(omega_L) - sigma_sca(omega_L)
```

Здесь эффективная поляризуемость берется из Фурье-компонент временного отклика.
Для нелинейного импульса это амплитудно-зависимая эффективная величина, а не
обычная линейная поляризуемость. Отрицательное
`sigma_abs = sigma_ext - sigma_sca` не обрезается. Его отрицательное значение
показывает, что эффективный дипольный отклик не удовлетворяет пассивному
оптическому балансу в принятых допущениях. Это может указывать на необходимость
radiation-reaction correction, а для нелинейного импульса также на вклад
преобразования частот, недостаточное временное окно или погрешность
рациональной аппроксимации. До выяснения причины такое значение нельзя
интерпретировать как материальное поглощение.

Старые поля `sigma_energy_cm2` и `sigma_spectral_cm2` пока сохраняются как
алиасы; второе всегда означало именно экстинкцию. Новые артефакты имеют
`schema_version = 2`.

## Физический смысл основных параметров

`--c-nm` - большая полуось вытянутой МНЧ. Увеличивает объем МНЧ и меняет
деполяризационный фактор, поэтому влияет на силу плазмонного диполя и положение
плазмонного резонанса.

`--a-nm` - малая полуось МНЧ. Вместе с `c` задает форму эллипсоида. От отношения
`c/a` зависит продольный плазмонный резонанс.

`--r-nm` - расстояние между центрами КТ и МНЧ. В дипольной модели связь
масштабируется как `1/R^3`, поэтому это один из самых сильных параметров.
Если КТ расположена на продольной оси, зазор примерно равен
`R - c - r_QD`. Ядро требует строго положительный зазор. По умолчанию
`c = 15 nm`, `r_QD = 2 nm`, `R = 18 nm`, поэтому зазор равен `1 nm`.
Положительный зазор исключает геометрическое перекрытие, но сам по себе не
доказывает применимость точечно-дипольного приближения на таком расстоянии.

`--qd-radius-nm` - радиус КТ для проверки неперекрывающейся геометрии. Нулевое
значение разрешено только как явно выбранный предел точечного излучателя.

`--G` - геометрический или эффективный фактор диполь-дипольной связи. В простой
точечной дипольной модели `G = 2` для продольной ориентации диполей вдоль линии
центров, а `G = -1` для поперечной ориентации. Значения намного больше 2 надо
понимать как эффективное усиление связи, а не как обычный угловой фактор.

`--eps-m` - диэлектрическая проницаемость окружающей среды. Она меняет
поляризуемость МНЧ, волновое число в формуле сечения и силу связи
`J = G / (eps_m R^3)`.

`--d-debye` - переходный дипольный момент КТ. Чем он больше, тем сильнее КТ
взаимодействует с полем и МНЧ, тем заметнее интерференция и тем легче насыщать
двухуровневую систему.

`--omega0-ev` - энергия перехода КТ. Она задает расстройку относительно лазера и
плазмонного резонанса. Именно расстройка во многом определяет фазу диполя КТ и
то, будет ли интерференция конструктивной или разрушительной.

`--gamma2-coherence-mev` - полная скорость затухания когерентности `Gamma2`
(HWHM в энергетических единицах), а не чистая дефазировка. Сохраняемый старый
алиас - `--gamma-dephasing-mev`. Физическая матрица плотности требует
`Gamma2 >= gamma1/2`; нарушение останавливает расчет до запуска решателя.

`--gamma-population-mev` - скорость релаксации населенности КТ. В линейном
спектре она почти не играет роли, но во временной нелинейной задаче определяет,
как быстро КТ возвращается в основное состояние и насколько выражено насыщение.

## Параметры лазерного импульса

`--omega-l-ev` - энергия фотона лазера. Обычно ее ставят в область, где
линейный спектр показал интересный Фано-провал или резонанс.

`--tau-fs` - длительность импульса. В коде это FWHM по интенсивности. Более
короткий импульс имеет более широкий спектр и сильнее смешивает частоты.

`--e0-min`, `--e0-max`, `--points` - сетка амплитуд электрического поля. По ней
строится зависимость от интенсивности, флюенса или площади импульса.

`--x-axis` - что откладывать по горизонтальной оси на графике:
`fluence` удобно для сравнения импульсов разной длительности по полной энергии,
`intensity` удобно для обсуждения насыщения в терминах пиковой мощности,
`pulse_area` удобно для двухуровневой физики КТ и рабиевских осцилляций.

`--post-fs` - до какого абсолютного времени после центра импульса продолжать
интегрирование. По умолчанию начальная оценка равна восьми временам затухания
самой медленной несвязанной когерентной моды КТ/МНЧ. Затем расчет автоматически
удваивает окно до трех раз, пока остаток хвоста не станет меньше `10^-3`.
Метрика хвоста - максимальный по диполям КТ, МНЧ и их сумме time-weighted RMS в
последних 5% физического времени; поэтому адаптивная сетка и взаимная компенсация
диполей не скрывают незатухший отклик. В CSV сохраняются `post_fs_effective`,
`response_tail_ratio`, `tail_below_tolerance` и `tail_extension_count`. Явное
значение `--post-fs` не расширяется автоматически и предназначено для ручной
проверки сходимости.

## Численные параметры аппроксимации и решателя

`--n-modes` - число лоренцевых мод в аппроксимации поляризуемости МНЧ. Обычно 4
достаточно для рабочей области, но при изменении спектрального окна стоит
проверять качество подгонки.

`--fit-min-ev`, `--fit-max-ev` - окно энергий, где подгоняется поляризуемость
МНЧ. Оно должно покрывать область лазера и плазмонного резонанса. Кандидат
подгонки принимается только при устойчивых полюсах и
`Im(alpha_fit) >= 0` с численным допуском на плотной конечной сетке заданного
окна; это дискретная проверка, а не доказательство знака между всеми узлами.
Минимальное значение и число узлов сохраняются в диагностике.

`--weight-center-ev`, `--weight-sigma-ev` - дополнительный вес в подгонке около
важной энергии. Если интересует узкая область около резонанса, вес помогает
улучшить точность именно там.

`--method`, `--rtol`, `--atol` - параметры `solve_ivp`. Для жесткой системы
обычно разумно начинать с `Radau`. После каждого решения дополнительно
проверяются конечность траектории, достижение конечного времени и положительность
матрицы плотности по условию `W^2 + Q^2 + P^2 <= 1`. До интегрирования также
вычисляются полюса полного Jacobian связанной системы около основного состояния;
набор с положительной спектральной абсциссой отклоняется как самовозбуждающийся
без внешнего поля. Fano scan исключает такие кандидаты из ранжирования.

## Как интерпретировать рост или спад сечения

Если в слабом поле связанная система имеет большую экстинкцию, чем голая МНЧ, то при
росте интенсивности КТ насыщается и ее вклад может уменьшаться. Тогда сечение
обычно падает.

Если в слабом поле есть Фано-провал, связанная система имеет меньшую экстинкцию, чем голая
МНЧ из-за разрушительной интерференции диполей. При росте интенсивности КТ
насыщается, разрушительная интерференция ослабевает, и спектральное сечение
может расти к значению голой МНЧ. Именно такой сценарий мы пытались получить
при подборе параметров.

## Автоматические проверки

Быстрый набор регрессионных тестов запускается без дополнительных пакетов:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Он проверяет нормировку интенсивности и fluence в среде, геометрический зазор,
условие `Gamma2 >= gamma1/2`, классификацию
`sigma_ext = sigma_abs + sigma_sca`, обратную совместимость старых имен и
положительность численной матрицы плотности, устойчивость полного Jacobian,
корректность контроля послепульсного хвоста и schema-2 артефактов.
