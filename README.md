# Квазистатические модели КТ–МНЧ

Расчётный тракт статьи о возбуждении коллоидной квантовой точки (КТ) вблизи
золотого вытянутого сфероида. КТ описывается матрицей плотности (уравнения
Блоха без приближения вращающейся волны), поле и диполь наночастицы (МНЧ) —
классической электродинамикой, а частотно-зависимая поляризуемость МНЧ во
временной задаче представляется причинной пассивной суммой лоренцевых мод.

Сравниваются две независимые оси:

- **пространственная** — точечно-дипольное приближение (DD) против полного
  квазистатического решения со сфероидальным ядром Грина (FQS);
- **материальная** — одноосцилляторная дисперсия золота против многополюсной.

## Структура

```
src/qdmnp/              ядра моделей и наблюдаемые
    pipeline.py         оркестровка расчёта (логика, тестируемая отдельно)
    full_qs_model.py    временная модель FQS
    spheroid_green.py   аналитическое ядро для КТ на оси
    spheroid_equatorial.py  ядро для КТ сбоку
    rational_fit.py     DD-модель и подгонка alpha(omega)
    passive_fit.py      причинная пассивная подгонка
    observables/        формулы зависимостей для рисунков статьи:
                        calculate_*.py считают, plot_*.py рисуют
    verification/       сверки с опубликованными результатами
scripts/run_article.py  точка входа: запуск всей последовательности
inputs/                 ARTICLE_INPUTS.toml — все входные параметры
docs/                   описание входов, план расчётов, протокол валидации
tests/                  тесты (392)
manuscript/             текст статьи (LaTeX)
results/                архив article_single_mnp отслеживается в Git;
                        остальные каталоги результатов игнорируются
qd_mnp_bem_validation.py          независимый решатель методом граничных
generate_spheroid_bem_fixtures.py элементов и генератор его фикстуры
```

`qd_mnp_bem_validation.py` намеренно оставлен вне пакета и не импортирует ни
одного модуля проекта: это независимый эталон для сверки аналитических ядер, и
его SHA256 заморожен в `tests/fixtures/spheroid_bem_v1.json`.

## Установка

```powershell
.\setup_env.ps1
```

Скрипт проверяет наличие `uv`, создаёт окружение по `uv.lock` и ставит сам
проект (`src`-layout), после чего `import qdmnp` доступен и в тестах, и в
подпроцессах калькуляторов.

## Запуск

```powershell
.\.venv\Scripts\python.exe scripts\run_article.py --dry-run   # проверить входы
.\.venv\Scripts\python.exe scripts\run_article.py --smoke     # быстрый прогон
.\.venv\Scripts\python.exe scripts\run_article.py             # полный расчёт
```

Полный расчёт занимает около 3.5 часов и завершается каталогом с данными,
рисунками, `article_results.json` и отчётом `index.html`. Прогон возобновляем:
повторный запуск с тем же `--output` продолжает с места остановки, пока входные
данные, исходники и версии библиотек не изменились.

Завершённый прогон для полуосей `c=15`, `a=b=10` нм хранится в
[`results/article_single_mnp/index.html`](results/article_single_mnp/index.html).
При переименовании архива исходные метаданные сохранены; новый расчёт с
изменёнными входами запускается в отдельный `--output`
([подробности](docs/ARTICLE_INPUTS.md)).

Тесты:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

## Документация

- `docs/ARTICLE_INPUTS.md` — смысл каждого входного параметра и его обоснование;

- `docs/ARTICLE_PIPELINE_VALIDATION.md` — протокол проверок и их результаты;
- `docs/PASSIVE_FIT_REFINEMENT.md` — подгонка дисперсии золота.
- [docs/MANUSCRIPT_RESULTS_AUDIT.md](docs/MANUSCRIPT_RESULTS_AUDIT.md) — сверка
  завершённого расчёта с формулами, рисунками и выводами статьи, исправленные
  расхождения и воспроизводимые проверки;
- [docs/PHYSICAL_PARAMETER_SOURCES.md](docs/PHYSICAL_PARAMETER_SOURCES.md) —
  источники физических входов, соглашения о скоростях и модельные допущения;
- [docs/MANUSCRIPT_REVIEW.md](docs/MANUSCRIPT_REVIEW.md) — предыдущая редакционная
  проверка от 21 сентября и источники экспериментальных рекомендаций.

Статья собирается из [manuscript/main.tex](manuscript/main.tex). Включены
аннотация, введение, модель, результаты, обсуждение с экспериментальными
рекомендациями, заключение и список использованных источников.

## Область применимости

Модель локальна, квазистатична и трактует КТ как точечный диполь. Не учтены
запаздывание, нелокальный отклик металла, туннелирование и конечный размер КТ;
порядок этих эффектов оценён и сохраняется в `units.json` каждого прогона.
Результаты условны в объёме принятой модели.
