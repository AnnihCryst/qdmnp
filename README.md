# Квазистатические модели КТ–МНЧ

Проект моделирует одну двухуровневую квантовую точку (КТ), расположенную в
ближнем поле одной вытянутой металлической наночастицы (МНЧ). КТ описывается
матрицей плотности, поле и диполь МНЧ — классической электродинамикой, а
частотно-зависимая поляризуемость МНЧ во временной задаче представляется суммой
плазмонных лоренцевых мод.

Исходная **legacy/native-модель проекта**, сохранённая для воспроизводимости,
использует:

- квазистатическое точечно-дипольное взаимодействие КТ–МНЧ;
- однородная вытянутая эллипсоидальная МНЧ с полуосями `c >= a`;
- независимый выбор положения КТ (`tip`/`equatorial`) и поляризации
  внешнего поля (`longitudinal`/`transverse`); геометрический фактор
  `G = 3 (e_L . r_D_hat)^2 - 1` принимает только значения `2` и `-1`;
- диэлектрическое локальное поле внутри КТ;
- пассивное разложение поляризуемости МНЧ по затухающим плазмонным модам;
- нелинейная динамика двухуровневой КТ без приближения слабого поля.

Дополнительно реализован новый full-QS backend: КТ остаётся точечным диполем и
двухуровневой системой, но МНЧ отвечает явно суммируемым рядом аналитических
сфероидальных гармоник до проверяемого порядка `n_max`. Оба backend имеют общий
слабополевой контракт и могут рассчитываться для одного и того же лазерного
импульса.

Параметры по умолчанию не следует называть «репликой Shah» или другого
литературного расчёта. Это самостоятельный сценарий для данной модели.
Сравнение со статьями выполняется позднее, явным набором сопоставимых
параметров и с учётом различий моделей.

## Временная проверка по McMillan et al., Fig. 4(c)

Это основной тест исходной динамической системы: 10-цикловый импульс
`sech` площади `5π` действует на CdSe-КТ и золотую сферу, после чего строится
населённость возбуждённого состояния `rho22(t)` для расстояний между центрами
`R = 80, 20, 13 nm`. Запуск без PDF сравнивает расчёт с численными ориентирами
из текста статьи:

```powershell
uv run python literature_reproductions\mcmillan2016_fig4c_full_qs.py
```

Если передать локальный PDF статьи, скрипт дополнительно оцифрует Fig. 4(c) и
запишет точечные ошибки относительно опубликованных кривых:

```powershell
uv run python literature_reproductions\mcmillan2016_fig4c_full_qs.py --article-pdf C:\path\to\mcmillan2016.pdf
```

По умолчанию выполняются также две численные проверки для наиболее сильной
связи `R=13 nm`: уточнение временного шага и сравнение 60/80/100 материальных
полюсов. Результаты сохраняются в `PNG`, `PDF`, `CSV`, `NPZ` и
`metadata.json` внутри `results/literature_mcmillan2016_fig4c/<timestamp>/`.

Здесь важно различать два индекса:

- `n` — порядок пространственной сферической/сфероидальной гармоники МНЧ;
  для совпадения с дипольной моделью статьи устанавливается `n=1`;
- `k` — номер лоренцева полюса материальной дисперсии золота; именно набор
  таких полюсов превращает частотно-зависимый отклик в причинную систему ОДУ.

Поэтому совпадение с Fig. 4(c) проверяет материальную память, обратную связь
КТ--МНЧ и уравнения Блоха в общем дипольном пределе. Оно не является
независимой проверкой высших пространственных порядков `n>1`; для них нужны
отдельные мультипольные эталоны.

## Математическая модель

Все внутренние уравнения решаются в атомных единицах. В формулах ниже
опущены коэффициенты преобразования в СИ, которые сосредоточены в функциях
конвертации проекта.

### Поляризуемость эллипсоидальной МНЧ

Для выбранной главной оси эллипсоида безразмерная квазистатическая функция
отклика равна

```text
chi_MNP(omega) = [epsilon_Au(omega) - eps_m]
                 / [eps_m + L (epsilon_Au(omega) - eps_m)].
```

Здесь `L` — деполяризационный фактор выбранной оси, а `eps_m` — вещественная
положительная диэлектрическая проницаемость однородной окружающей среды.
Физическая поляризуемость в принятой в коде системе единиц имеет вид

```text
alpha_MNP(omega) = C chi_MNP(omega),
C = eps_m a^2 c / 3.
```

Комплексная `epsilon_Au(omega)` берётся из табличных оптических данных.
Между измеренными узлами проект явно и без экстраполяции линейно
интерполирует `n(omega)` и `k(omega)`, затем вычисляет
`epsilon=(n+i k)^2`. Такая локальная интерполяция сохраняет `n,k >= 0` и не
создаёт spline-overshoot.
Квазистатическая формула не содержит запаздывания, динамической
деполяризации и radiation-reaction correction.

### Спектральное разложение дипольного отклика в legacy-backend

Чтобы использовать тот же материальный отклик во временной области,
`chi_MNP` аппроксимируется как

```text
chi_fit(omega) = chi_inf
               + sum_k f_k / (omega_k^2 - omega^2 - i gamma_k omega).
```

Мгновенный член не является свободной константой подгонки. Он фиксируется
высокочастотным пределом используемой материальной модели
`epsilon_Au(omega -> infinity)=1`:

```text
chi_inf = (1 - eps_m) / [eps_m + L (1 - eps_m)].
```

В частности, при стандартном `eps_m=1` получаем строго `chi_inf=0`.

Рабочая аппроксимация ограничивает параметры каждой моды условиями

```text
f_k >= 0,    omega_k > 0,    gamma_k > 0.
```

Поэтому при `omega > 0` каждая лоренцева мода имеет неотрицательную мнимую
часть. Это структурная пассивность скалярного modal fit, а не только проверка
нескольких точек после unconstrained-подгонки. Во временной области каждой
моде соответствует осциллятор

```text
q_k'' + gamma_k q_k' + omega_k^2 q_k = f_k F_MNP(t),
mu_MNP = C [chi_inf F_MNP + sum_k q_k].
```

Число мод `--n-modes` следует увеличивать только вместе с проверкой ошибки
аппроксимации на всём нужном спектральном окне.

В этом разделе описан именно legacy-backend, где пространственный отклик МНЧ
заранее ограничен одной дипольной степенью свободы. Несколько `q_k` с одним
пространственным профилем — не разные сфероидальные мультиполи, а пассивная
лоренцева реализация частотной дисперсии табличного золота. В full-QS-backend
высшие пространственные порядки присутствуют явно; у каждого порядка `n` есть
собственная причинная материальная реализация с индексом `k`. По умолчанию для
legacy-дипольной восприимчивости используются девять вспомогательных
спектральных мод. Частоты и ширины отдельных членов нельзя автоматически
отождествлять с девятью физическими собственными плазмонами: особенно
высокоэнергетические полюса могут в первую очередь реализовывать межзонную
дисперсию золота и точность на конечном fit-окне.
Расчёт не принимается как production-fit, если
нормированные RMS-ошибки `chi` или `1/chi` превышают 2.5% либо максимальная
поточечная относительная ошибка `chi` превышает 5%. Эти критерии вычисляются
на плотной интерполированной сетке с обязательным включением табличных узлов и
границ окна. Регрессионный тест повторно считает ошибки на другой, ещё более
плотной смещённой сетке: проверка только в редких исходных узлах запрещена,
поскольку она может пропустить узкий искусственный резонанс между ними.
Число мод дополнительно ограничено количеством независимых исходных
табличных точек: для `N` мод код считает `3N+1` вещественных fit-координат и
требует как минимум четыре дополнительные вещественные связи. Плотная
интерполяционная сетка контролирует поведение между измеренными точками, но не
выдаётся за новую независимую экспериментальную информацию.

### Положение КТ и поляризация поля

МНЧ — осесимметричный вытянутый сфероид с центром в начале координат и
большой полуосью вдоль `z`:

```text
(x^2 + y^2) / a^2 + z^2 / c^2 = 1,   c > a.
```

Положение КТ и направление внешнего поля задаются двумя **независимыми**
параметрами. `qd_position` определяет вектор `r_D` от центра МНЧ к центру КТ,
где `h` — поверхностный зазор. Из-за осевой симметрии экваториальное положение
без потери общности берётся со стороны положительной оси `x`:

```text
tip         ->  r_D = (0, 0, c + h)
equatorial  ->  r_D = (a + h, 0, 0)
```

`field_polarization` задаёт единичный вектор поляризации `e_L` внешнего поля
`E_L(t) = E_L(t) e_L`; дипольный момент перехода КТ берётся вдоль того же
направления:

```text
longitudinal ->  e_L = (0, 0, 1)
transverse   ->  e_L = (1, 0, 0)
```

`R = |r_D|` — расстояние между центрами, измеренное вдоль выбранного
направления. Поддерживаются все четыре комбинации:

| `qd_position` | `field_polarization` | `e_L` и `r_D` | Ветвь поляризуемости МНЧ | `G` |
|---|---|---|---|---:|
| `tip` | `longitudinal` | параллельны | `L_long` | `2` |
| `tip` | `transverse` | перпендикулярны | `L_trans` | `-1` |
| `equatorial` | `longitudinal` | перпендикулярны | `L_long` | `-1` |
| `equatorial` | `transverse` | параллельны | `L_trans` | `2` |

Оба выбора влияют на разные части задачи и поэтому не заменяют друг друга:

* **поляризация** выбирает главную ось МНЧ, вдоль которой берётся
  деполяризационный фактор `L`, а значит и весь плазмонный спектр
  `chi_MNP(omega)`;
* **взаимное направление** `e_L` и `r_D` задаёт геометрический фактор
  дипольного тензора.

Так как в каждой из четырёх комбинаций и `e_L`, и `r_D` направлены вдоль
главных осей сфероида, оба диполя поляризуются строго вдоль `e_L`, а
квазистатический тензор дипольного поля сводится к скалярной связи

```text
G = 3 (e_L . r_D_hat)^2 - 1,
J = G / (eps_m R^3).
```

`G` в этой модели не является подгоночной «силой связи»: он вычисляется из
фактических векторов `r_D` и `e_L`. Значения, отличные от `2` и `-1`, а в
особенности прежние `G > 2`, выходят за рамки выбранной точечно-дипольной
геометрии и отклоняются; несогласованный с геометрией `G` в параметрах также
отклоняется. Физически связь меняется через `R`, `eps_m`, геометрию и
дипольный момент КТ.

Прежний параметр `--orientation long|trans` сохранён как псевдоним
`--field-polarization longitudinal|transverse`. Одновременная передача обоих
имён допускается только если они согласованы. Поведение по умолчанию
(`--qd-position tip`) численно совпадает с предыдущими версиями проекта.

```powershell
.\.venv\Scripts\python.exe qd_mnp_linear_spectrum.py --qd-position equatorial --field-polarization transverse --r-nm 12
```

### Геометрический зазор

Поверхностный зазор измеряется вдоль фактического направления на КТ, поэтому
используется полуось МНЧ именно в этом направлении:

```text
tip         ->  gap = R - c - r_QD
equatorial  ->  gap = R - a - r_QD
```

Одно и то же `R` поэтому может быть недопустимым на торце и допустимым
сбоку: при `c=15 nm`, `a=7 nm` и `r_QD=2 nm` расстояние `R=10 nm` даёт
`gap=1 nm` в экваториальной геометрии и перекрытие частиц в торцевой.

Ядро требует `gap > 0`, то есть частицы не могут касаться или перекрываться.
Положительный зазор — необходимое, но не достаточное условие применимости
точечно-дипольной модели: при очень малом `gap` могут стать существенными
высшие мультиполи, пространственная структура КТ, нелокальность металла,
туннелирование и перенос заряда.

Поэтому результаты также содержат четыре безразмерных диагностических
параметра: `k_m c`, `k_m R`, `c/R` и `r_QD/R`. Требования модели имеют
асимптотический смысл: `k_m c << 1` — квазистатический отклик самой МНЧ;
`k_m R << 1` — отсутствие запаздывания в связи `J ~ 1/R^3`; `c/R << 1` —
замена всей МНЧ одним диполем; `r_QD/R << 1` — использование поля в центре
для конечной КТ. Код использует уровень `0.3` только как warning-guide, а не
как универсальную строгую границу. В частности, стандартная близкая геометрия
`c=15 nm`, `R=18 nm` проходит проверку gap, но имеет `c/R=0.833`; её следует
считать качественным исследованием выбранной дипольной модели, а не
количественно мультипольно-сошедшимся описанием реальной частицы.

### Локальное поле КТ и соглашение о дипольном моменте

КТ рассматривается как переход внутри диэлектрической сферы с вещественной
фоновой проницаемостью `eps_qd`. Лоренцевский множитель локального поля равен

```text
l = 3 eps_m / (eps_qd + 2 eps_m).
```

Он входит в модель с обеих физически различных сторон:

```text
mu_QD,out = l d P,
F_MNP     = E_inc + J mu_QD,out,
E_QD,micro = l (E_inc + J mu_MNP),
Omega     = 2 d E_QD,micro.
```

Эти формулы записаны для соглашения `bare_internal`; при
`effective_external` в них используется применяемый множитель `l_eff = 1`.

`P` — одна из компонент вектора Блоха, `mu_QD,out` — диполь КТ, создающий
поле во внешней среде, а `E_QD,micro` — поле, действующее на переход внутри
КТ. Поэтому обратная связь КТ–МНЧ содержит `l^2`, и тот же множитель появляется
в линейной поляризуемости КТ.

Ключевое соглашение задаётся явно через `--qd-dipole-convention`:

- `bare_internal`: `d_au`/`--d-debye` — неэкранированный межзонный матричный
  элемент; тогда код применяет показанный выше множитель `l` к микроскопическому
  полю и к внешнему диполю;
- `effective_external`: переданное `d` уже считается эффективным внешним
  диполем; тогда применяемый множитель равен единице, чтобы не учитывать
  screening второй раз.

По умолчанию выбран `effective_external`. Причина не физическая подгонка, а
честная обратная совместимость: старое значение `7.5e-29 C m` было найдено в
legacy-коде без зафиксированного источника и без указания, является ли оно
bare- или effective-диполем. Поэтому его нельзя доказательно переклассифицировать
как bare и автоматически уменьшить отклик КТ в `l^2` раз. При сравнении со
статьёй соглашение и значение `d` необходимо выбирать вместе по определениям
конкретной статьи. Нельзя смешивать bare- и effective-значения в одной серии
расчётов.

`eps_qd` — только вещественная положительная фоновая проницаемость КТ.
Резонансный двухуровневый переход уже описывается матрицей плотности и не
должен повторно входить в `eps_qd`. Дисперсия и потери фоновой проницаемости КТ
в текущей реализации не моделируются.

### Матрица плотности КТ

Двухуровневая КТ задаётся действительными компонентами Блоха `W`, `Q`, `P`:

```text
W' = Omega Q - gamma1 (W + 1),
Q' = -omega0 P - Omega W - Gamma2 Q,
P' =  omega0 Q - Gamma2 P.
```

`W = -1` — невозбуждённая КТ, `omega0` — частота перехода, `gamma1` — скорость
релаксации населённости, `Gamma2` — полная скорость затухания когерентности.
Для совместимости с физической матрицей плотности требуется

```text
Gamma2 >= gamma1 / 2,
W^2 + Q^2 + P^2 <= 1 + tolerance.
```

Чистая дефазировка равна `Gamma2 - gamma1/2`. Параметр
`--gamma2-coherence-mev` задаёт именно полную `hbar Gamma2`, а не чистую
дефазировку.

### Согласованность диполя и радиационного распада

Один и тот же внешний диполь перехода должен быть согласован с эталонной
скоростью спонтанного излучения в однородной среде:

```text
gamma_rad,hom = sqrt(eps_m) omega0^3 |d_external|^2
                / (3 pi epsilon0 hbar c^3),
d_external = l d_bare       для bare_internal,
d_external = d_effective    для effective_external.
```

Ядро вычисляет это значение и сохраняет отношение
`gamma1/gamma_rad,hom`. Оно не подменяет заданный `gamma1`: рядом с МНЧ
электромагнитная плотность состояний может усиливать или подавлять излучение,
а выбранная электростатическая модель сама не рассчитывает LDOS и Purcell
decay. Поэтому доступны режимы `warn`, `raise` и `ignore`, но это именно
диагностика согласованности исходного набора параметров.

Legacy-профиль по умолчанию здесь заведомо не откалиброван количественно:
`d_external = 22.484 D` соответствует в однородном вакуумном окружении
`gamma_rad,hom = 7.08e8 s^-1` (около `1.41 ns`), тогда как сохранённый старый
`gamma1 = 3.33e7 s^-1` соответствует `30 ns`. Отношение около `0.047` вызывает
предупреждение. До появления общего литературного источника для `d`,
`gamma1`, соглашения local-field и среды эти defaults следует считать
диагностическим legacy-набором, а не параметрами конкретной КТ.

### Разрешение временных масштабов

Адаптивность `solve_ivp` не отменяет необходимости разрешать быстрые
осцилляции при вычислении Фурье-интегралов и работы поля. Верхняя частота для
ограничения шага включает несущую, `omega0`, все modal-полюса, модуль всех
полюсов полного линейного Jacobian и сильнополевую частоту Раби

```text
Omega_R(t) = 2 d l |E_inc(t) + J mu_MNP(t)|.
```

На один самый быстрый период допускается не менее 20 шагов. Сначала
используется оценка по амплитуде падающего поля; после решения вычисляется
максимальная самосогласованная `Omega_R(t)`. Если плазмонное локальное поле
сделало её больше, расчёт автоматически повторяется с меньшим `max_step`.
Число таких уточнений и обе оценки частоты сохраняются в диагностике.

Работа `integral E_inc d(mu_total)/dt dt` и carrier-frequency Фурье-отношение
вычисляются квадратурой по адаптивной временной сетке. Регрессионный
strong/few-cycle тест повторяет расчёт с `max_step/2` и требует относительного
изменения меньше `10^-5` для работы и `10^-4` для `alpha_eff(omega_L)`.
Это проверяет штатное правило 20 точек на самый быстрый период; для нового
экстремального набора параметров такой half-step тест следует повторять, а не
считать один `solve_ivp.success` доказательством сходимости квадратуры.

## Спектральное окно импульса

Плазмонные моды воспроизводят материал только внутри
`[--fit-min-ev, --fit-max-ev]`; продолжение fit за пределы этого окна не имеет
проверенного физического смысла. Поэтому:

- прямой запрос `alpha_from_fit` вне окна по умолчанию запрещён;
- для вещественного гауссова импульса вычисляется точная доля его
  положительно-частотной спектральной энергии внутри fit-окна;
- после решения отдельно FFT-проверяется спектр самосогласованного поля
  `F_MNP=E_inc+J mu_QD`, поскольку сильная нелинейная КТ может генерировать
  компоненты, которых не было во входном импульсе;
- отдельно проверяется спектр самого ответа `mu_MNP(t)`: вход может находиться
  в окне, а нелинейно сформированный выход — уже нет;
- временной расчёт по умолчанию останавливается, если снаружи окна находится
  более `10^-3` энергии входного или фактического возбуждающего спектра;
- фактические доли покрытия и утечки сохраняются в диагностике результата.

Для более короткого импульса спектр шире. Если проверка не проходит, следует
расширить fit-окно и заново подобрать плазмонные моды, а не разрешать
неконтролируемую экстраполяцию.

## Линейный и импульсный отклик

`qd_mnp_linear_spectrum.py` аналитически решает слабополевую связанную задачу и
вычисляет поляризуемость всей системы. Он используется как эталон слабого поля
для временного решателя и для поиска интерференционного Фано-подобного
провала. Минимум отношения coupled/bare сам по себе ещё не доказывает
асимметричную линию Фано и не определяет параметр `q`, поэтому scan называет
найденные строки кандидатами, а не автоматически установленными
Фано-резонансами.

Ошибка fit контролируется также на уровне конечной наблюдаемой. Линейный и
Fano-like расчёты повторяют ту же связанную алгебру с
`alpha_MNP`, взятой непосредственно из интерполированных `n,k`, и сравнивают
её с результатом девяти modal-осцилляторов. Для линейного спектра сохраняются
нормированные RMS/max ошибки относительно глобального масштаба, а также
локальная относительная ошибка каждой точки с floor `10^-3` от глобального
масштаба (чтобы не делить на физический ноль). Пределы равны соответственно
7% и 10%; строка `modal_observable_converged=True` требует выполнения обоих.
Выходная energy-сетка линейного спектра дополнительно обязана иметь шаг не
больше `min(0.5 meV, Gamma2/4)`: именно по этой сетке печатаются глубина и
положение провала, поэтому редкий набор точек не может получить ложный PASS.
Для провала дополнительно сохраняются ошибка
отношения coupled/bare в целевой энергии и сдвиг положения минимума. Текущие
regression-пределы равны `0.01` по отношению и глубине минимума, `1.5 meV` по
положению минимума, а шаг scan-сетки должен быть одновременно не больше
`0.5 meV` и `Gamma2/4`. Последнее условие не позволяет принять сетку, которая
формально мелка в абсолютных единицах, но груба относительно узкой линии КТ.
Это пределы приемки численной
реализации, а не заявление о 7-процентной физической точности; фактические
ошибки обязательно остаются в CSV.

В Fano-scan эти понятия намеренно разделены. Поле
`accepted_for_modal_numerical_ranking` означает только, что modal-реализация и
scan-сетка сошлись относительно прямого material response. Флаги
`suppression_at_target` и `dip_in_window` требуют отношения coupled/bare меньше
единицы и не позволяют назвать чистое усиление «провалом»; для попадания в
top-list подавление в целевой энергии должно подтверждаться также прямой
material-reference ветвью. Поле
`quantitative_physical_applicability` отдельно требует выполнения
квазистатического, near-field и point-dipole ориентиров, а также согласованности
`d/gamma1` с однородной эталонной радиационной скоростью. Старое совместимое
поле `accepted_for_quantitative_ranking` истинно только при одновременном
выполнении численных, suppression- и физических условий.

`qd_mnp_pulse_absorption_sweep.py` решает полные нелинейные уравнения Блоха и
modal-осцилляторы. Интенсивность и fluence в среде нормируются с показателем
преломления `sqrt(eps_m)`. После импульса интегрирование продолжается до
затухания отклика. Автоматическое окно удваивается до выполнения tail-критерия;
если лимит расширений исчерпан, production-расчёт завершается ошибкой и не
возвращает несошедшиеся наблюдаемые. Явный `--post-fs` остаётся диагностическим
режимом и выдаёт предупреждение при незатухшем хвосте.

`pulse_area_isolated_qd = l_QD d E0 sqrt(2 pi) sigma` — обычная площадь
гауссовой огибающей в RWA для изолированной КТ. Временной решатель при этом
интегрирует полное вещественное поле без RWA. Поэтому для few-cycle импульсов
эта величина служит только координатой калибровки и не включает
самосогласованное плазмонное усиление локального поля.

В импульсном выводе различаются:

```text
sigma_energy_transfer = W_inc / fluence,
W_inc = integral E_inc(t) d(mu_total)/dt dt,
```

Для временного окна, в котором поле исчезло на обеих границах, пассивная
устойчивая система должна иметь `W_inc >= 0` с учётом численного допуска.
Значимо отрицательная работа теперь прерывает расчёт, а факт и допуск
проверки сохраняются в диагностике.

Для строгой квазистатической поляризуемости отдельно выводятся следующие
оценки на выбранной частоте:

```text
sigma_qs_work = k / epsilon0 Im[alpha_QS],
sigma_Rayleigh_est = k^4 / (6 pi epsilon0^2) |alpha_QS|^2,
optical_theorem_residual = sigma_qs_work - sigma_Rayleigh_est.
```

`alpha_QS` в native-модели не содержит radiation-reaction dressing. Поэтому
`k Im(alpha_QS)/epsilon0` — ведущая квазистатическая оценка работы/потерь, а
рэлеевское излучение — отдельная поправка более высокого порядка. Их нельзя
одновременно объявлять точными `extinction` и `scattering`, а разность нельзя
объявлять чистым материальным поглощением: для такого разбиения потребовалась
бы радиационно согласованная поляризуемость и соответствующее изменение всей
самосогласованной модели.

Старые поля `sigma_ext`, `sigma_sca` и `sigma_abs` сохранены только как
schema-алиасы: соответственно для `sigma_qs_work`, отдельной Rayleigh-оценки
и формального `optical_theorem_residual`. Знак residual не обрезается, но ни
положительный, ни отрицательный residual не является здесь самостоятельной
физической оценкой material absorption/gain.

`W_inc/fluence` — непосредственно вычисленное сечение передачи энергии от
падающего импульса моделируемым дипольным степеням свободы. В слабом линейном
пределе оно сходится к `sigma_qs_work`. Для сильного короткого импульса
`alpha_eff(omega_L)=mu(omega_L)/(eps_m E(omega_L))` является
амплитудно-зависимой Фурье-характеристикой, а Rayleigh-оценка только на
`omega_L` описывает когерентную компоненту на несущей, но не полное излучение
по всем нелинейно сгенерированным частотам.

Проверка `W_inc >= 0` подтверждает знак внешней работы и пассивность полного
законченного pulse-расчёта. Это не полное поканальное тождество
`external work = stored energy + bath losses`: для такого разложения пришлось
бы отдельно и согласованно определить энергию связи `-J mu_MNP mu_QD`, потери
каждой modal-степени свободы и феноменологические Lindblad-каналы КТ. Текущий
код не называет optical-theorem residual таким энергетическим балансом.

## Рекомендуемый порядок расчёта

1. Построить линейный спектр для одной физической ориентации:

```powershell
.\.venv\Scripts\python.exe qd_mnp_linear_spectrum.py --orientation long --r-nm 18 --energy-min-ev 2.0 --energy-max-ev 2.08 --target-ev 2.042
```

Эта команда одновременно является тестом modal-реализации. Canonical N=9
выбран потому, что для обеих ориентаций проходит глобальную и локальную
проверки в интервале `2.00--2.08 eV`; прежний N=8 проходил глобальные fit-метрики,
но не локальный observable-критерий. Любой новый warning
`modal_observable_converged=False` при другой геометрии, среде или спектральном
окне игнорировать нельзя: нужно увеличить число мод/перенастроить fit и заново
проверить сохранённые global и per-row local errors.
Именно `2.00--2.08 eV` и 201 точка теперь являются defaults линейного CLI.
Широкий обзорный диапазон следует задавать явно вместе с достаточно большим
`--points`; он может потребовать иной modal fit и обязан заново пройти
observable-критерий.

2. Если нужен кандидат на Фано-подобный провал, просканировать расстояние
   между центрами, а не искусственный `G`:

```powershell
.\.venv\Scripts\python.exe qd_mnp_fano_scan.py --orientation long --r-min-nm 18 --r-max-nm 40 --r-points 61 --r-spacing linear --gamma-population-mev 3.02 --gamma2-coherence-mev-values 1.51 2.0 2.78 3.02 --top 10
```

Точки с `R <= c + r_QD`, с `Gamma2 < gamma1/2` или с неустойчивым полным
линейным Jacobian отбрасываются. Все остальные конечные строки сохраняются в
CSV, но top-список включает только численно сошедшиеся строки с реальным
подавлением `ratio_at_target < 1` и рядом явно печатает
`physical_applicability = PASS/FAIL`. Поэтому численное ранжирование внутри
выбранной native-модели не смешивается с утверждением о количественной
физической применимости дипольного приближения.

3. Проверить выбранные `R`, `omega0`, `Gamma2` и `d` в полном линейном спектре.

4. Только затем запустить нелинейную импульсную серию с тем же набором
   физических параметров:

```powershell
.\.venv\Scripts\python.exe qd_mnp_pulse_absorption_sweep.py --orientation long --r-nm 18 --tau-fs 5 10 25 --points 50 --x-axis fluence --no-show
```

Эти команды сохраняют legacy-нормировку `effective_external`, поэтому
`eps_qd` в них намеренно не передаётся: при этом соглашении локальный множитель
равен единице. Параметр `--eps-qd` начинает влиять на уравнения только вместе с
`--qd-dipole-convention bare_internal`; тогда одновременно необходимо задать
`--d-debye` как согласованный bare-матричный элемент из того же литературного
набора параметров. Старое число `d` нельзя автоматически считать bare.

Геометрия задаётся двумя независимыми флагами. `--qd-position` выбирает
`tip` или `equatorial`, а `--field-polarization` — `longitudinal` или
`transverse` (прежний `--orientation long|trans` остаётся псевдонимом
поляризации). Все четыре комбинации поддерживаются одинаково; `G` при этом
вычисляется из геометрии, поэтому явное переопределение `--G` по-прежнему
запрещено.

```powershell
.\.venv\Scripts\python.exe qd_mnp_pulse_absorption_sweep.py --qd-position equatorial --field-polarization transverse --r-nm 12 --tau-fs 5 --points 20 --no-show
```

Экваториальные запуски требуют собственного `--r-nm`: расстояние отсчитывается
от центра, а зазор — от короткой полуоси `a`, поэтому значения, разумные для
торцевой геометрии, дают там неоправданно большой зазор.

## Полный квазистатический отклик вытянутого сфероида

Legacy-ядро сохранено без изменения и по-прежнему доступно как контрольная
точечно-дипольная модель. Новый backend заменяет только пространственный блок
взаимодействия КТ--МНЧ. Для поля заданной поляризации он вычисляет

```text
p_M       = A E_inc + B p_QD,
E_MNP@QD  = B E_inc + K p_QD.
```

Основная геометрия — однородный вытянутый сфероид `c > a`. Точный предел
`c = a` реализован отдельными аналитическими сферическими весами и служит как
поддерживаемой геометрией, так и строгим benchmark сфероидальных формул.

Ядро использует фактический вектор `r_D`, а не эмпирическую поправку к
коэффициенту связи. В вытянутых сфероидальных координатах

```text
x = f sqrt((xi^2-1)(1-eta^2)) cos(phi),   z = f xi eta,   f = sqrt(c^2 - a^2)
```

торцевая КТ лежит на оси, где `eta_D = 1` и `xi_D = R/f`, а экваториальная —
в плоскости `z = 0`, где `eta_D = 0` и `xi_D = sqrt(1 + (R/f)^2)`.

Из-за этого меняется и набор удерживаемых мод. Точечный источник **на оси**
возбуждает единственный азимутальный порядок: `m=0` для продольного диполя КТ
и `m=1` для поперечного. Источник **вне оси** возбуждает все `m`, поэтому
экваториальная геометрия суммирует полное семейство `(n, m)`:

```text
K      = sum_(n,m) w_nm chi_nm,
chi_nm = (eps_p - eps_m) / [eps_m + L_nm (eps_p - eps_m)],
w_nm   = |A_nm| |g_nm| (e_d . grad u_nm(r_D))^2 / (eps_m f),
A_nm   = (-1)^m (2 - delta_m0) (2n+1) [(n-m)!/(n+m)!]^2,
g_nm   = -L_nm P_n^m(xi_0) / Q_n^m(xi_0),
L_nm   = Q_n^m P_n^m' / (Q_n^m P_n^m' - P_n^m Q_n^m').
```

В экваториальной плоскости `e_x = e_xi` и `e_z = e_eta`. Поэтому поперечный
(радиальный) диполь КТ дифференцирует `Q_n^m` и оставляет `P_n^m(0)`, то есть
удерживает моды с чётным `n-m`, а продольный (касательный) диполь оставляет
`Q_n^m` и дифференцирует `P_n^m`, то есть моды с нечётным `n-m`. Яркая мода —
`n=1` с `m=0` для продольной поляризации и `m=1` для поперечной; она стоит
первой в списке, и для неё выполняется взаимность `w_1 = C lambda^2`, где
`lambda` — обобщение `J` на точное сфероидальное ядро.

Все `P_n^m`, `Q_n^m` и их производные вычисляются в логарифмическом масштабе
по положительным рекуррентным соотношениям без вычитаний, поэтому высокие
порядки не переполняются. Диагностика `degrees` и `azimuthal_orders`
экспортирует метку `(n, m)` каждой моды, а усечение `truncate(N)` выполняется
по пространственному порядку `n`, то есть удерживает все азимутальные порядки
оставленных степеней.

Число мод экваториального ядра растёт как `n_max^2/4` вместо `n_max`
(например `n_max=80` даёт около 1640 мод), и во временной задаче каждая мода
несёт собственную материальную реализацию. Поэтому экваториальные импульсные
расчёты следует начинать с умеренного `--spatial-order-max` и повышать его по
частотной проверке сходимости.

Экваториальная геометрия также сильнее растягивает диапазон `L_nm`. Для
торцевой поперечной геометрии `L_n - L_1` укладывается примерно в
`[-0.02, +0.06]`, а для экваториальной поперечной — в `[-0.15, +0.08]`. Тот же
девятиполюсный причинный fit материала переносится преобразованием
`chi_n = chi_1 / [1 + (L_n - L_1) chi_1]` на более широкий интервал, поэтому
проверка `--fit-quality-policy` может зафиксировать поточечную ошибку выше
штатных 6%. Число полюсов ограничено количеством табличных точек в fit-окне,
поэтому такой запуск следует вести с `--fit-quality-policy warn` и явно
сохранённой диагностикой, а не с молчаливым ужесточением лимитов.

`A` имеет размерность `a0^3`, `B` безразмерен, `K` имеет размерность
`a0^-3`. В legacy-модели принудительно выполняется

```text
B_legacy = A J,
K_legacy = A J^2.
```

В аналитическом сфероидальном решении `A` и `B` относятся к яркой гармонике
`n=1`, а реакционный оператор содержит полный ряд

```text
K_full = sum_n K_n.
```

Поэтому сравнение выполняется сразу для трёх ветвей:

1. `legacy` — поле КТ заменено его значением в центре точечной МНЧ;
2. `spheroid_n1` — точная проекция точечного источника на яркую гармонику;
3. `spheroid_full` — к предыдущему добавлены высшие пространственные моды.

При конечном расстоянии `spheroid_n1` не обязан совпадать с `legacy`. Точное
тождество имеет вид `K_1=B^2/A` без комплексного сопряжения; формулы legacy
восстанавливаются только в дальнем пределе `R/c -> infinity`.

Частотное сравнение строит спектр, непосредственно используемые в литературе
кривые `Re K(omega)` и `Im K(omega)`, накопленные суммы
`sum_(n<=N) K_n`, ошибку относительно конечного `N` и зависимость от зазора:

```powershell
.\.venv\Scripts\python.exe qd_mnp_spheroid_green_comparison.py --orientations long trans --energy-min-ev 1.8 --energy-max-ev 2.3 --energy-points 1001 --n-max 80
```

Если `--multipole-orders` не указан, точки накопительной кривой автоматически
строятся из `--n-max`; поэтому уменьшение `--n-max` не конфликтует со скрытым
фиксированным списком. Проверка замены `N/2 -> N` применяется ко всей
энергетической сетке и к каждому запрошенному зазору. По умолчанию
`--convergence-policy raise` запрещает экспорт несошедшегося ряда; режимы
`warn` и `ignore` предназначены для явно диагностических запусков.

Импульсный сценарий использует один и тот же набор физических параметров,
один и тот же Gaussian pulse и один и тот же причинный fit материала в обеих
ветвях:

```powershell
.\.venv\Scripts\python.exe qd_mnp_spheroid_pulse_comparison.py --orientation long --spatial-order-max 80 --pulse-energy-ev 2.042 --pulse-tau-fs 5 --pulse-e0-au 1e-5
```

Без `--post-fs` используется безопасный режим по умолчанию: общее для обеих
моделей окно начинается с наиболее медленной оценки затухания и
удваивается, пока компонентные хвосты не удовлетворят одному критерию. Для
legacy отдельно проверяются полный диполь, КТ/МНЧ-компоненты, реакционное поле
и когерентность КТ; full-QS дополнительно проверяет взвешенные выходы и
внутренние координаты/скорости пространственно-материальных осцилляторов.
`--tail-policy` задаёт действие при несходимости хвоста, а
`--positivity-policy` и `--positivity-tolerance` одинаково применяются к обеим
матрицам плотности. Выбранные политики, фактическое окно и отдельные old/new
tail ratios записываются в `metadata.json`. Опция `--post-fs 100` замораживает
конец окна для отдельного диагностического сравнения, но не отменяет итоговую
tail-проверку.

По умолчанию два временных решателя запускаются конкурентно; параметр
`--sequential` включает последовательный режим для отладки. Каждый запуск
получает отдельный каталог даже при старте нескольких сценариев в одну секунду.
Результат содержит `pulse_summary.csv`, общую интерполированную сетку в CSV/NPZ,
исходные адаптивные old/new сетки и full-QS modal outputs в
`pulse_traces_adaptive.npz`, solver diagnostics и `pulse_dynamics.png`. Число
точек общей сетки автоматически повышается до ограничения, заданного самой
высокой разрешаемой частотой интеграторов; запрошенное, требуемое и фактическое
число точек записываются в `metadata.json`.

Ни `--spatial-order-max 20`, ни `80` не являются универсальным критерием
сходимости. Для стандартного зазора 1 nm значение `20` может быть
недостаточным. Сначала следует запустить частотный сценарий, проверить
`half_order_relative_change` при замене `N/2 -> N`, затем повторить важные
импульсные наблюдаемые с увеличенным `N`. При уменьшении зазора требуемое число
гармоник быстро растёт. Временной сценарий дополнительно проверяет ряд на всём
окне материального fit и по умолчанию завершает несошедшийся запуск через
`--spatial-convergence-policy raise`; `warn`/`ignore` нужно выбирать явно только
для диагностики зависимости от `N`.

Временной backend не подгоняет `A`, `B` и `K` независимо. Из одного причинного
Lorentz-представления яркой восприимчивости `chi_1` каждая пространственная
мода строится по точному материальному преобразованию

```text
chi_n = chi_1 / [1 + (L_n - L_1) chi_1].
```

Для каждой моды проверяются точность относительно табличной `epsilon_Au`,
неотрицательность мнимой части и полюса причинной реализации. Для умеренного
размера полного линеаризованного QD--MNP Jacobian крайние собственные значения
проверяются непосредственно. Для большой штатной системы используется явно
помеченный сертификат устойчивости пассивной взаимной связи: устойчивость
подсистем, отсутствие статической soft-mode и отдельно сертифицированный по
невязке наибольший по модулю полюс. Такой сертификат не определяет правый полюс
связанной системы и не задаёт границу скорости её затухания. Поэтому в этой
ветви `spectral_abscissa_au` экспортируется как `null`, а
`decay_rate_estimate_au` — только как эвристическая начальная оценка окна;
окончательное принятие временного расчёта всегда определяется компонентной
tail-проверкой и, в auto-режиме, расширением окна. Тип сертификата, доступность
спектральной абсциссы и точность proxy явно записываются в диагностику. Модель
остаётся строго
квазистатической, локальной и точечно-дипольной со стороны КТ: она не добавляет
ретардацию, radiation reaction, нелокальность металла или автоматически
вычисленную Purcell/Lindblad-поправку.

## Квалифицированная реконструкция Fig. 2(a) Yan et al. (2008) новым full-QS ядром

Скрипт `literature_reproductions/yan2008_fig2a.py` реконструирует верхнюю панель
Fig. 2 из [Yan et al., Phys. Rev. B 77, 165301
(2008)](https://doi.org/10.1103/PhysRevB.77.165301). Это наиболее прямой
литературный тест нового пространственного ядра: в статье и в коде
рассматриваются одна сферическая Au-МНЧ, одна точечная КТ на оси, строгая
локальная квазистатика и полный ряд сферических мультиполей.

Вычисляемая комплексная энергия обратного воздействия имеет вид

```text
hbar G_N(omega) = d_bare^2 l_QD^2 sum_(n=1..N) K_n(omega),
l_QD = 3 eps_e / (eps_s + 2 eps_e).
```

Здесь `G_N` — комплексная константа самодействия КТ через поляризацию МНЧ при
сохранении мультиполей до порядка `N`; `Re G_N` задаёт сдвиг энергии экситона,
а `Im G_N` — дополнительное уширение, связанное с передачей энергии в металл.
`K_n` — коэффициент реакционного поля `n`-го сферического мультиполя,
`d_bare` — нескринированный диполь межзонного перехода КТ, `l_QD` — фактор
локального поля сферической КТ, `eps_e` — относительная проницаемость среды,
`eps_s` — фоновая относительная проницаемость полупроводниковой КТ.

Запуск с параметрами литературного профиля:

```powershell
.\.venv\Scripts\python.exe -m literature_reproductions.yan2008_fig2a
```

Для Fig. 2(a) сама статья Yan явно задаёт радиус Au-сферы `R0=15 nm`, расстояние
между центрами `Rd=20 nm`, `eps_s=6` и оптические данные Au Johnson--Christy.
Однако `eps_e` и абсолютный диполь перехода в описании этой панели повторно не
напечатаны. Defaults честно дополняют профиль значениями `eps_e=1` и
`d_bare=e*0.65 nm` из цитируемой авторами работы Zhang et al., Phys. Rev. Lett.
97, 146804 (2006). Эта межстатейная привязка явно записывается в
`metadata.json`; она не выдаётся за параметр, непосредственно указанный в Yan.

Каждый запуск сохраняет:

- `yan2008_fig2a_full_qs.png` — `Re G_N` и `Im G_N` для `N=1,...,10`;
- `yan2008_fig2a_curves.csv` — значения full-QS и независимо вычисленной
  формулы (15) Yan на одной энергетической сетке;
- `metadata.json` — источник каждого параметра, SHA-256 локального PDF,
  положения и высоты максимумов, отношение `N=10` к `N=1` и ошибки сравнения.

Наложенные пустые маркеры формулы (15) являются аналитическим контролем
соглашений и нормировки. Чёрными крестами с погрешностями показаны только две
низкоточные оценки максимумов `N=10`, снятые с 220-dpi изображения издательского
PDF. Статья не публикует исходный численный массив Fig. 2(a), поэтому эти точки
явно помечены как графическое считывание, а скрипт не сообщает фиктивный
pointwise RMSE по пикселям. При параметрах по умолчанию положения обоих пиков
отличаются от графического считывания менее чем на `0.01 eV`, а их высоты —
примерно на `-4.0%` (`Re G_10`) и `-8.4%` (`Im G_10`). Это визуальная контрольная
проверка, а не утверждение о совпадении в пределах погрешности считывания. Точно,
до машинной погрешности, проверяется другое утверждение: сферический предел
full-QS совпадает с формулой (15) Yan при одинаковой диэлектрической функции.
Воспроизводится именно частотная full-QS зависимость
Fig. 2(a), а не импульсная динамика и пока не нижняя панель с полным поглощением.

## Сравнение с Shah et al. (2013)

Скрипт `qd_mnp_shah2013_comparison.py` строит аналоги рисунков 1--4 из
[официальной публикации Shah et al., Phys. Rev. B 88, 075411
(2013)](https://journals.aps.org/prb/abstract/10.1103/PhysRevB.88.075411),
используя геометрию и внешние воздействия статьи, но **уравнения native-модели
этого проекта**. Проверенные более точные численные константы взяты также из
[авторского набора статьи и Supplemental
Material](https://mdsoar.org/items/b3d49ba8-dc5f-4b24-9d27-75b1be2fa949).

Это не DDA/CQED-реплика статьи. Цель расчёта уже и диагностически полезнее:
проверить, какие линии, насыщение и импульсную динамику предсказывает именно
наша квазистатическая точечно-дипольная модель для заявленной авторами
геометрии. Без оцифрованных кривых статьи скрипт не вычисляет pointwise RMSE и
не выдаёт визуальное сходство за количественное совпадение.

### Физическая геометрия и параметры

В статье рассматривается не одна МНЧ, а симметричная структура
Au--CdSe--Au:

| Величина | Значение | Использование в native-расчёте |
|---|---:|---|
| большая полуось каждой Au-МНЧ `c` | `15 nm` | продольная поляризуемость эллипсоида |
| малая полуось каждой Au-МНЧ `a` | `10 nm` | объём и деполяризационный фактор |
| зазор между поверхностями Au-МНЧ | `6 nm` | расстояние центров `D=36 nm` |
| радиус центральной CdSe-КТ | `2 nm` | геометрическая проверка перекрытия |
| КТ--МНЧ, центр--центр | `R=18 nm` | связь каждой пары КТ--МНЧ |
| КТ--МНЧ, поверхность--поверхность | `1 nm` | физический gap |
| проницаемость среды `eps_m` | `2.25` | поляризуемости, связи и нормировка поля |
| энергия перехода КТ | `2.042 eV` | `omega0` и центральная частота импульса |
| диполь перехода КТ | `13.91 D` | связь поля с матрицей плотности |
| FWHM интенсивности импульса | `20 fs` | гауссова огибающая |

Поле направлено вдоль общей оси частиц. Поэтому для связи каждой пары
точечных диполей используется не подгоночное число, а продольный
геометрический множитель `G=2`. Интенсивность и fluence переводятся в
амплитуду поля с показателем преломления среды `sqrt(eps_m)`.

Значения статьи `d_s=2994 D`, `hbar gamma_s=150.2 meV` и
`hbar g=10.841 meV` относятся к **одной эффективной яркой моде всего
металлического димера**, которую авторы получили подгонкой DDA-отклика. Они не
присваиваются каждой из двух native-МНЧ: такое присваивание удвоило бы уже
эффективную степень свободы и смешало бы две разные модели. В нашем расчёте
каждая Au-МНЧ вместо этого получает поляризуемость эллипсоида из bulk-данных
Johnson--Christy. Константы эффективной моды сохраняются в metadata и
используются только там, где это явно указано, например при вычислении
литературной оценки Purcell-скорости.

Параметр `eps_QD,infinity=5.8` также сохраняется в наборе статьи, но
`d_q=13.91 D` используется с соглашением `effective_external`. Тем самым
диполь статьи считается уже эффективным внешним диполем, а диэлектрический
local-field factor не применяется к нему второй раз. Изменять это соглашение
отдельно от определения `d_q` нельзя.

### Почему две МНЧ не требуют двух независимых плазмонных состояний

Физически в структуре действительно две металлические частицы. Однако
семиклассические уравнения самой статьи уже заменяют весь димер одной
эффективной яркой дипольной модой. Поэтому наличие двух МНЧ на рисунке не
означает, что в редуцированной модели Shah должны присутствовать два
независимых плазмонных осциллятора.

Новый скрипт решает другую, более явную native-задачу: он оставляет две
поляризуемости отдельных эллипсоидов и добавляет их взаимное дипольное поле.
Для каждой МНЧ до учёта симметрии уравнения имеют вид

```text
q_s,k'' + gamma_k q_s,k' + omega_k^2 q_s,k = f_k F_s,
mu_s = C [chi_inf F_s + sum_k(q_s,k)],
C = eps_m a^2 c / 3,
```

где индекс `s=1,2` обозначает частицу, а несколько `q_s,k` реализуют
частотную дисперсию золота, но не являются разными пространственными
мультиполями. Поля в полной двухчастичной постановке равны

```text
F_1 = E_inc + J mu_QD + K mu_2,
F_2 = E_inc + J mu_QD + K mu_1,

J = 2 / (eps_m R^3),
K = 2 / (eps_m D^3).
```

Частицы идентичны, КТ находится строго посередине, а однородное поле возбуждает
их в фазе. Поэтому симметричное подпространство `mu_1=mu_2=mu_s` является
инвариантным, и система точно редуцируется в рамках точечно-дипольного
приближения:

```text
F_s = E_inc + J mu_QD + K mu_s,
E_QD = l_QD [E_inc + 2 J mu_s],
mu_total = 2 mu_s + mu_QD.
```

Мгновенный член `chi_inf F_s` содержит само поле `F_s`, поэтому в коде он
исключается алгебраически:

```text
F_s = [E_inc + J mu_QD + K C sum_k(q_k)]
      / [1 - K C chi_inf].
```

В частотной области та же редукция даёт поляризуемость свободного димера

```text
alpha_dimer(omega) = 2 alpha_single(omega)
                      / [1 - K alpha_single(omega)].
```

Антисимметричная ветвь не возбуждается в выбранной геометрии, но скрипт
отдельно проверяет устойчивость и симметричных, и антисимметричных полюсов.
Полная вещественная time-domain система для `N` лоренцевых членов имела бы
`4N+3` переменных: по координате и скорости каждой моды у каждой МНЧ плюс три
компоненты Блоха. Симметрия уменьшает её до `2N+3` без изменения физического
ответа яркой ветви. Полная система понадобится только при смещении КТ из
центра, разных частицах, неодинаковом локальном окружении или возбуждении,
которое смешивает яркую и тёмную ветви.

### Связь с центральным ядром

`qd_mnp_rational_fit.py` действительно служит центральным API материала и
одиночной КТ--МНЧ системы, но `HybridQDPlasmonModel.solve()` не является
универсальным many-particle решателем. В нём структурно зафиксированы одна
величина `mu_MNP`, одно расстояние `R` и поля

```text
F_MNP = E_inc + J mu_QD,
E_QD  = l_QD (E_inc + J mu_MNP).
```

Для димера здесь отсутствуют как член `K mu_other`, так и сумма полей
`J mu_1 + J mu_2`. Поэтому вызвать существующий `model.solve()` без изменения
нельзя: это численно решило бы прежнюю одночастичную задачу, хотя входные
параметры назывались бы параметрами димера.

Вместо изменения проверенного ядра скрипт вводит локальный адаптер
`SymmetricDimerQDPlasmonModel`. Он повторно использует из ядра:

- атомные единицы и преобразования в СИ;
- `HybridSystemParams` и все проверки параметров КТ;
- Johnson--Christy material response и пассивный `RationalLorentzFit`;
- `GaussianPulse`, соглашения о диполе и матрицу плотности;
- формулы линейной поляризуемости КТ и QS work-loss cross section.

Адаптер добавляет только геометрию второй МНЧ: коэффициент `K`, множитель `2J`
в поле КТ, восстановление `mu_total=2mu_s+mu_QD` и соответствующие правые части
ОДУ. При `--refit` одиночный `HybridQDPlasmonModel` заново строит пассивное
`N=10` разложение одной Au-МНЧ на окне `0.8--3.0 eV`; обычный запуск использует
детерминированный кэш результата того же fitter, чтобы не повторять долгую
подгонку. Таким образом, центральные уравнения Блоха и modal-осцилляторов не
переписываются в новую физическую модель, но цепочка самосогласованных полей
корректно расширяется на симметричный димер.

### Скорости релаксации и два честных профиля

Для марковской двухуровневой матрицы плотности должно выполняться

```text
Gamma2 = gamma1 / 2 + gamma_phi,
gamma_phi >= 0,
```

иначе динамика не соответствует полностью положительному Lindblad/GKSL
генератору. Из параметров Supplemental Material формула corrected-SC статьи
даёт

```text
hbar gamma1_eff = 3.01649 meV,
hbar Gamma2,paper = 1.265 meV,
gamma1_eff / 2 = 1.50825 meV.
```

Следовательно, напечатанная пара имеет `Gamma2 < gamma1_eff/2`. Ядро проекта
намеренно не позволяет обойти эту проверку. Скрипт предлагает два явно
названных варианта:

| `--decay-profile` | `hbar gamma1` | `hbar Gamma2` | Смысл |
|---|---:|---:|---|
| `naive` | `0.000268 meV` | `1.265134 meV` | свободная КТ; `1.265 meV` трактуется как чистая температурная дефазировка |
| `purcell_cp` | `3.01649 meV` | `2.77325 meV` | эффективный Purcell decay статьи плюс та же чистая дефазировка; профиль по умолчанию |

`purcell_cp` физически допустим для двухуровневого Lindblad-описания, но не
равен буквально напечатанной в статье паре ширин. Кроме того, текущая
электростатическая модель не вычисляет LDOS и Purcell decay из собственной
геометрии: значение `gamma1_eff` импортируется феноменологически из статьи.
Поэтому результаты двух профилей следует показывать раздельно, а различие
между ними считать неопределённостью сопоставления моделей, не численной
ошибкой решателя.

### Стационарная и импульсная цепочки

Линейный расчёт использует аналитическую частотную поляризуемость симметричного
димера и КТ. CW-ветвь на каждой частоте самосогласованно находит стационарную
инверсию `W`, затем вычисляет комплексные гармонические диполи; число найденных
физических корней записывается в диагностику, чтобы нелинейная ветвь не
выбиралась молча.

Для импульсов production-серия интегрирует медленные комплексные амплитуды тех
же modal/Bloch-уравнений во вращающейся системе координат. Второй порядок
каждого лоренцева осциллятора заменён его положительно-частотной RWA-ветвью;
на несущей она имеет тот же лоренцев знаменатель, а на ширине 20-fs импульса
является тем же приближением медленной огибающей, которое проверяли авторы
статьи. Это существенно ускоряет sweep, но не превращает расчёт в CQED.
Скрипт проверяет покрытие спектра fit-окном, положительность матрицы плотности и
затухание хвоста после импульса.

Рисунок 4 статьи получен CQED-расчётом. Соответствующий файл проекта показывает
только semiclassical-аналог: населённость КТ, когерентные диполи и их фазы из
одно-временной матрицы плотности. Он не воспроизводит квантовые корреляции,
фотонную статистику или вакуумный шум.

### Терминология и предел количественного сравнения

Для сопоставимости с осью статьи скрипт выводит величину

```text
k Im[alpha_total(omega)] / epsilon0.
```

В статье она обозначена как `sigma_abs`. В строгой электродинамической
терминологии проекта это ведущая квазистатическая оценка работы/потерь
(`quasistatic work loss`), а не отдельно доказанное material absorption и не
радиационно согласованное точное extinction. Для строгого разделения на
absorption и scattering потребовались бы radiation-reaction dressing и
согласованная оптическая теорема, которых в native-модели нет. Название поля
`paper_work_loss_cm2` в CSV намеренно сохраняет и форму ординаты статьи, и
корректную семантику проекта.

Самое существенное физическое ограничение данного сравнения —

```text
c / R = 15 / 18 = 0.833.
```

Это значительно больше консервативного ориентира проекта `c/R <= 0.3` для
замены конечной МНЧ точечным диполем. При 1-nm зазоре КТ--МНЧ неоднородность
поля и высшие мультиполи могут быть существенными. Статья учитывает
пространственный отклик металлического димера с помощью DDA и затем подгоняет
его одной эффективной яркой модой; наш адаптер связывает два точечных
эллипсоидальных диполя. Поэтому разумными целями являются знак пассивного
отклика, наличие и положение интерференционного провала, тренды насыщения и
изменение импульсной динамики. Точного совпадения амплитуд и всех характерных
интенсивностей заранее ожидать нельзя, а расхождение само по себе ещё не
указывает на ошибку в реализованных ОДУ.

## Сравнение с Sadeghi (2009)

`qd_mnp_sadeghi2009_comparison.py` строит аналоги рисунков 2--7 из
[Sadeghi, Nanotechnology 20, 225401
(2009)](https://doi.org/10.1088/0957-4484/20/22/225401). Это наиболее прямое
из трёх литературных сравнений: в статье рассматриваются одна сферическая
МНЧ, одна двухуровневая КТ, продольная ориентация `G=2`, квазистатика и RWA.
То есть отдельная физическая модель здесь не вводится — используется
сферический предел native-модели.

### Какие параметры действительно известны

В статье явно напечатаны:

| Величина | Значение |
|---|---:|
| время релаксации населения КТ | `0.8 ns` |
| полная скорость затухания когерентности | `2.7 ns^-1` |
| bare-диполь перехода | `0.65 e nm = 31.22084 D` |
| слабое поле | `1 W/cm^2` |
| сильное поле | `1 kW/cm^2` |
| расстояния центров `R` | `100, 20, 17, 15 nm` |

В PDF отсутствуют численные радиус МНЧ, `eps_environment`, `eps_QD`, энергия
перехода, радиус КТ и источник диэлектрической функции металла. Скрипт
восстанавливает стандартный набор из Zhang--Govorov--Bryant, на который
ссылается Sadeghi:

```text
a_MNP = 7.5 nm, eps_environment = 1, eps_QD = 6,
hbar omega_21 = 2.5 eV.
```

Эти значения в `metadata.json` помечены как
`inferred_from_sadeghi_reference_9`, а не как якобы напечатанные в статье.
Радиус КТ не указан ни в самой статье, ни в использованном списке параметров;
поэтому `r_QD=0` (точечная КТ) отдельно помечен как `project_model_choices`,
а не как восстановленная константа литературы.
Дополнительно исходная работа использовала Palik Au, тогда как native-модель
проекта использует Johnson--Christy. Поэтому точная численная реплика по
одному `sadeghi2009.pdf` невозможна; скрипт проверяет переносимость поведения
на текущую модель.

### Как формулы статьи переходят в код

Для сферы `c=a`, `L=1/3`, поэтому безразмерный response ядра равен

```text
chi_MNP = 3 gamma,
gamma = (epsilon_Au - eps_environment)
        / (epsilon_Au + 2 eps_environment).
```

После умножения на `C=eps_environment*a^3/3` получается ровно

```text
alpha_MNP = eps_environment a^3 gamma.
```

Локальный множитель КТ

```text
l_QD = 3 eps_environment / (eps_QD + 2 eps_environment) = 3/8
```

применяется к bare-диполю статьи. При стандартной нормировке интенсивности
это даёт `Omega0=0.50825 ns^-1` для `1 W/cm^2` и `16.0723 ns^-1` для
`1 kW/cm^2`, то есть восстанавливает округлённые `0.5` и `16 ns^-1` из
статьи.

В RWA-адаптере используется когерентность статьи `s=rho_21` и соглашение
`Omega_script=-Omega_paper`, после чего решается система

```text
Omega = Omega0(t) [1 + J alpha_MNP] + eta s,
eta   = d^2 l_QD^2 J^2 alpha_MNP,
J     = 2 / (eps_environment R^3),

dot rho22 = 2 Im[conj(Omega) s] - gamma1 rho22,
dot s     = -(Gamma2 + i Delta) s + i Omega (1 - 2 rho22).
```

Это не новая динамика: формулы получаются из тех же полей
`F_MNP=E+J mu_QD`, `E_QD=l_QD(E+J mu_MNP)` и тех же уравнений матрицы
плотности ядра после RWA и адиабатического исключения МНЧ. Пассивная modal
поляризуемость берётся из `RationalLorentzFit`; обычный запуск использует
детерминированный кэш `N=9`, а `--refit` повторяет подгонку через
`HybridQDPlasmonModel`.

Для каждой стационарной точки скрипт дополнительно строит аналитический
Jacobian физических RWA-уравнений по переменным
`(rho22, Re rho21, Im rho21)` и требует

```text
max Re[eigenvalue(J)] < 0.
```

Поэтому нулевой residual сам по себе недостаточен: неустойчивая ветвь не будет
молча экспортирована как физический стационарный отклик. Аналитический Jacobian
отдельным тестом сравнивается с центральной конечной разностью. Число
проверенных точек и наибольшая вещественная часть собственного значения
сохраняются в секции `steady_state_stability` каждого `metadata.json`, поэтому
README не подменяет актуальный результат числами от старого запуска.

Полный `HybridQDPlasmonModel.solve()` намеренно не вызывается: статья сама
работает в RWA и исследует несколько наносекунд, тогда как carrier-resolved
решатель должен был бы разрешить оптический период порядка фемтосекунд.
Плазмон релаксирует на много порядков быстрее 0.4-ns включения поля, поэтому
`alpha_from_fit(omega_L)` является адиабатическим пределом тех же модальных
осцилляторов.

### Знак скорости возбуждения

В equations (4)--(5) статьи есть внутренняя знаковая несогласованность: при
буквальном совместном использовании изолированная КТ ушла бы в отрицательное
население. На Fig. 3--5 обозначенная авторами величина `G` действительно
нарисована отрицательной при положительном `rho22`.

Поэтому CSV содержит физическую величину и две диагностические:

```text
physical_excitation_ns_inv = 2 Im[conj(Omega_script) rho_21],
literal_paper_G_ns_inv = -2 Im[Omega_script rho_21],
negated_physical_excitation_ns_inv = -physical_excitation_ns_inv.
```

Первая входит в физически положительную матрицу плотности. Вторая буквально
воспроизводит напечатанную авторами формулу после замены соглашения для
`Omega`; третья отдельно показывает простой отрицательный знак физической
скорости. При комплексной `Omega` вторая и третья величины не совпадают, и
подмена любой из них в физическом уравнении населения запрещена тестом.

Точная функция включения поля в статье также не задана. Default — логистическая
амплитудная ступень с центром `10 ns` и точно определённым временем нарастания
10--90% `0.4 ns`; это записывается как project assumption.

`0.3` для точечно-дипольной МНЧ. Поэтому совпадение трендов здесь физически
значимее точного совпадения амплитуд: высшие мультиполи могут быть заметны.

Есть и внутренняя численная проблема самой Fig. 7: при почти изолированном
`R=100 nm`, напечатанных скоростях и `Delta=0.3 meV` уравнения дают
`rho22` порядка `0.005`, тогда как график имеет масштаб порядка `0.2`.
Последний соответствовал бы расстройке примерно `0.03--0.04 meV`. Ни замена
Palik на Johnson--Christy, ни взаимодействие с далёкой МНЧ не объясняют
десятикратную разницу. Скрипт сохраняет буквальные `+/-0.3 meV` и фиксирует
противоречие в metadata, не вводя скрытый масштабный коэффициент.

## Сравнение с Cheng et al. (2007)

`qd_mnp_cheng2007_comparison.py` строит аналоги Fig. 2--3 и строго ограниченный
предельный тест для Fig. 4 из [Cheng et al., Optics Letters 32, 2125--2127
(2007)](https://opg.optica.org/ol/abstract.cfm?uri=ol-32-15-2125).

### Почему нужен геометрический адаптер

В статье поле всегда направлено вдоль длинной оси вытянутой Au-МНЧ. Поэтому
поляризуемость в обеих конфигурациях остаётся продольной `L_long`. Меняется
только положение КТ:

```text
to-the-end:  g= 2, d=q b + r_QD + gap,
by-the-side: g=-1, d=  b + r_QD + gap.
```

В общем API проекта `orientation="trans"` одновременно выбирает `G=-1`,
поперечную поляризуемость и проверку осевого gap. Такой вызов не представлял
бы боковую геометрию Cheng. Локальный адаптер поэтому всегда вычисляет
продольную

```text
alpha_MNP = [eps_environment a b^2 / 3]
            [epsilon_Au-eps_environment]
            / [eps_environment + L_long(epsilon_Au-eps_environment)],
```

но независимо подставляет `g=2/-1` и соответствующее расстояние. Центральный
файл не изменяется.

Параметры статьи:

| Величина | Значение |
|---|---:|
| малая полуось `b` | `6 nm` |
| aspect ratio | `q=a/b` |
| `eps_environment`, `eps_QD` | `2.25`, `10` |
| свободная `gamma_rad0` | `0.08 ns^-1` |
| `(lambda, r_QD)` | `(600 nm,3.2 nm)`, `(750 nm,6.6 nm)`, `(900 nm,9.5 nm)` |
| gaps | `2, 4, 6 nm` |
| дополнительный decay для Fig. 4 | `zeta=10 ns^-1` |

Для Fig. 2 рассчитываются две явно различённые нормировки:

```text
f_Cheng  = 1 + g alpha_MNP/(epsilon_eff d^3),
epsilon_eff = (2 eps_environment + eps_QD)/3,

f_native = 1 + g alpha_MNP/(eps_environment d^3),
gamma_rad = |f|^2 gamma_rad0.
```

Первая повторяет соглашение статьи, вторая показывает отношение локального
drive в текущей native-конвенции. Обе колонки сохраняются; различие нельзя
маскировать подбором параметров.

### Почему Fig. 3 и Fig. 4 не имеют единственной реплики

Нерадиационная скорость в статье задаётся

```text
G_feedback = 2 g^2 mu_QD^2 alpha_MNP
             / (hbar epsilon_eff^2 d^6),
gamma_nonrad = Im G_feedback.
```

Но численное `mu_QD` не напечатано. Поэтому каждый запуск сохраняет два
профиля:

- `radiative_consistent`: внешний диполь однозначно восстанавливается из
  `gamma_rad0=0.08 ns^-1` в однородной среде, затем переводится в bare internal
  dipole тем же `l_QD`, что использует ядро;
- `figure_calibrated`: `mu_internal=1.82 D`, восстановленное по масштабу
  красных максимумов Fig. 3 для текущих Johnson--Christy данных. Это fit к
  рисунку, а не константа статьи.

Второй профиль нельзя одновременно считать согласованным с напечатанным
`gamma_rad0=0.08 ns^-1`. После того же local-field преобразования
`l_QD=0.465517` диполь `1.82 D` соответствует внешнему диполю `0.847 D` и
однородной радиационной скорости:

| `lambda` | скорость из `1.82 D`, `ns^-1` | доля от `0.08 ns^-1` |
|---:|---:|---:|
| `600 nm` | `0.001563` | `0.0195` |
| `750 nm` | `0.0008004` | `0.0100` |
| `900 nm` | `0.000463` | `0.00579` |

Таким образом, при 750 нм расхождение составляет примерно фактор 100.
`figure_calibrated` используется только как диагностическая калибровка
масштаба Fig. 3; физически самосогласованным профилем остаётся
`radiative_consistent`. Кроме того, один и тот же `1.82 D` применяется к трём
разным радиусам КТ только потому, что статья не сообщает отдельные диполи.

Текст статьи сообщает максимум `0.8 ns^-1` для `g=2`, тогда как сама Fig. 3(a)
показывает примерно `0.2 ns^-1`; metadata фиксирует и эту неоднозначность.

Для Fig. 4 указаны только площадь импульса и `zeta`, но отсутствуют амплитуда,
длительность и временная форма. При ненулевом decay одинаковая площадь разных
импульсов даёт разную динамику. Поэтому скрипт не выдумывает недостающий
импульс и выводит только strong-drive zero-feedback proxy теоремы площадей:

```text
rho22(theta) = sin^2(|f| theta/2),
period / pi = 2/|f|.
```

Эта формула требует резонансного возбуждения bare-КТ
`delta/Omega0 -> 0`, а также одновременно
`gamma10/Omega0 -> 0`, `Gamma2/Omega0 -> 0` и
`|G_feedback|/Omega0 -> 0`. Последнее условие удаляет не только потери, но и
когерентную часть обратной связи, которая в полных уравнениях Cheng меняет
расстройку КТ. Поэтому это полезный тест усиления поля и изменения Rabi period,
но не общий «когерентный предел» и не воспроизведение dissipative Fig. 4.
Неизвестный диполь КТ в этот proxy не входит, поэтому кривые не дублируются для
двух dipole profiles.

### Почему q-sweep использует direct material response

Fig. 2--3 и area-only Fig. 4 зависят только от `alpha(omega_L)` при одной
частоте. `alpha_from_material` является целевой функцией, которую пассивное
разложение ядра затем аппроксимирует для временных ОДУ. Строить отдельный
нелинейный modal fit для сотен значений `q` означало бы только добавить
fit-ошибку к тем же частотным точкам, не добавляя временной памяти. Поэтому
Cheng-скрипт использует формулу и Johnson--Christy material API ядра напрямую;
это явно записано в metadata и не выдаётся за propagation модальных координат.

Чтобы это упрощение не разорвало связь с реализованным в проекте модальным
ядром, каждый запуск выполняет отдельный `modal_audit` для `q=1,3,4`. Для
каждого `q` строится тот же пассивный `N=9` Lorentz fit, который создаёт
`HybridQDPlasmonModel`, и при 600, 750 и 900 нм проверяется

```text
delta_alpha = |alpha_modal-alpha_direct|/|alpha_direct| <= 0.06.
```

Максимальная ошибка кэшированных fit равна примерно `5.46%` (`q=4`, 750 нм).
Отдельно проверяются `Im alpha_modal >= 0`, неотрицательные силы мод,
положительные затухания и отрицательные вещественные части всех полюсов.
Поскольку `Im alpha` в некоторых точках очень мала, для канала потерь
используется устойчивая нормировка по максимальному `Im alpha` для каждого `q`
с пределом `10%`. Кэш содержит параметры, полученные реальным ядром; ключ
`--refit-modal-audit` пересоздаёт три fit через неизменённый
`HybridQDPlasmonModel`.

## Автоматические физические и численные проверки

Тесты и runtime-валидация должны контролировать как минимум:

- `Im alpha_MNP(omega) >= 0` и `f_k >= 0` для пассивных плазмонных мод;
- физический высокочастотный предел `chi_inf`, отсутствие modal-полюсов выше
  верхней границы табличных данных и запрет экстраполяции самого fit;
- устойчивость полюсов modal fit и полного Jacobian;
- `Gamma2 >= gamma1/2`;
- согласованность `d_external` и однородной эталонной `gamma_rad`;
- положительность матрицы плотности через длину вектора Блоха;
- строго положительный геометрический `gap`;
- совпадение слабополевого time-domain отклика с `linear_spectrum`;
- сходимость физических наблюдаемых при увеличении `post_fs`;
- покрытие fit-окном спектров импульса, MNP-drive и `mu_MNP`;
- сходимость конечного linear/Fano-like observable при замене modal fit на
  прямую интерполированную материальную поляризуемость;
- разрешение несущей, modal/hybrid полюсов и сильнополевой частоты Раби;
- неотрицательность внешней работы в пассивном pulse-complete расчёте;
- строгую QS-семантику: `k Im(alpha_QS)/epsilon0`, отдельная Rayleigh-оценка и
  их diagnostic residual не выдаются за точное разбиение material absorption.

Успешное завершение `solve_ivp` само по себе не подтверждает физическую
корректность результата.

## Теоретическая опора реализации

- Геометрические множители `G=2/-1`, квазистатическая связь и локальное поле
  сферической КТ: [Zhang, Govorov, Bryant, Phys. Rev. Lett. 97, 146804
  (2006)](https://arxiv.org/html/cond-mat/0606590v2).
- Два local-field factor в самодействии КТ–металл и границы дипольного
  приближения по отношению к мультипольному расчёту:
  [Artuso et al., Phys. Rev. B 83, 235406
  (2011)](https://cfm.ehu.es/nanophotonics/publications/PhysRevB.83.235406.pdf).
- Согласование действительных уравнений Блоха с классическим затухающим
  плазмонным осциллятором: [Shah and Scherer, Phys. Rev. B 88, 075411
  (2013)](https://journals.aps.org/prb/abstract/10.1103/PhysRevB.88.075411) и
  [авторский Supplemental Material](https://mdsoar.org/items/b3d49ba8-dc5f-4b24-9d27-75b1be2fa949).
- Различие геометрических поверхностных eigenmodes и спектральной modal
  реализации дисперсии: [Sandu, Plasmonics 8, 391–402
  (2013)](https://doi.org/10.1007/s11468-012-9403-z).
- Локальное поле и эталонная радиационная скорость диполя в однородной
  диэлектрической среде: [Thränhardt et al., Phys. Rev. B 65, 035327
  (2002)](https://doi.org/10.1103/PhysRevB.65.035327).
- Необходимость radiation correction для применения оптической теоремы к
  электростатической поляризуемости: [Le Ru, Somerville, Auguié
  (2013)](https://arxiv.org/abs/1210.0936).

Эти источники обосновывают форму уравнений, но не означают, что текущий набор
параметров воспроизводит конкретную фигуру или эксперимент из какой-либо из
статей.

## Область применимости и ограничения

Оба backend требуют, чтобы размеры системы были малы по сравнению с длиной
волны, а КТ допускала двухуровневое марковское описание. Их пространственные
приближения различны, поэтому ограничения нельзя объединять утверждением, что
«текущая модель не содержит высших мультиполей».

### Общие ограничения legacy и full-QS

Обе модели не включают:

- запаздывание, динамическую деполяризацию и самодействие излучения;
- конечный объём КТ: она является точечным диполем, поэтому неоднородность поля
  внутри реальной КТ не разрешается;
- нелокальный отклик металла, электронное туннелирование, перенос заряда и
  химическое взаимодействие при субнанометровых зазорах;
- размерно-зависимое поверхностное рассеяние электронов в золоте: используется
  bulk-диэлектрическая функция Johnson--Christy без добавки вида `A v_F/L`,
  поэтому linewidth малой МНЧ нельзя считать автоматически скорректированным;
- дисперсию и потери фоновой `eps_qd`;
- многоуровневую структуру КТ, фононную немарковскую динамику и спектральную
  диффузию;
- квантование плазмонного поля и полную квантовую статистику фотонов;
- самосогласованный расчёт `gamma1` и `Gamma2` из электромагнитной функции
  Грина окружения.

### Дополнительное ограничение legacy-backend

Legacy-модель заменяет всю МНЧ одним индуцированным диполем и использует поле
в её центре, то есть не содержит высших **пространственных** сфероидальных
порядков в обратной связи с КТ. Поэтому её условие `c/R << 1` существенно и
результат при малом зазоре следует считать контрольным, а не
мультипольно-сошедшимся.

### Ограничения full-QS-backend

Full-QS-backend снимает именно это legacy-ограничение: реакционное поле точечной
КТ содержит явно суммируемые высшие электростатические порядки МНЧ. Однако это
не полноволновой расчёт. Реализация ограничена однородным вытянутым сфероидом
или его точным сферическим пределом,
КТ на его оси симметрии и выбранными продольной/поперечной поляризациями;
пространственный ряд обрезается на `n_max` и обязан пройти проверку сходимости.
Однородное лазерное поле возбуждает яркий порядок `n=1`, тогда как высшие
порядки входят в реакцию МНЧ на неоднородное поле близкого точечного диполя КТ.

Отдельный численный предел касается сильно вытянутых частиц. При большом
отношении осей поверхность `xi_0 = c/f` подходит вплотную к единице, и
табличная оценка `Q_n(xi)` вместе с её hypergeometric-запасным вариантом
перестаёт быть представимой в двойной точности при высоких `n`. Для
`a=3 nm`, `c=30 nm` расчёт проходит до `n_max` порядка 120 и явно падает с
`FloatingPointError` при `n_max=200`; это относится к обеим геометриям КТ,
поскольку ограничение лежит в `m=0`-столбце. Экваториальная КТ достигает
предела при меньшем `n_max`, так как её `xi_D = sqrt(1+(R/f)^2)` ближе к
единице, чем торцевое `xi_D = R/f`. Расчёт в такой ситуации не выдаёт
испорченных чисел, а останавливается.

В частности, текущие ОДУ распространяют одно-временные средние компоненты
Блоха и когерентные диполи. Они позволяют исследовать линейный coherent
response, интерференционный провал, возбуждение импульсом, Rabi flopping и
передачу энергии, но не вычисляют двухвременную корреляционную функцию
флуоресценции, некогерентный спектр Моллоу или `g^(2)`. Для этого понадобились
бы квантовая регрессия/квантование поля и LDOS-зависимое спонтанное излучение.
По той же причине два пика текущей semiclassical-модели корректно называть
normal-mode или Rabi-like splitting; термин «вакуумное расщепление Раби» сам
по себе здесь не обоснован, поскольку вакуумные флуктуации в уравнения не
входят.

Поэтому положительный gap и хорошие численные тесты ещё не доказывают
количественную применимость модели к конкретному эксперименту. Следующий этап
валидации — сравнение её предельного поведения и наблюдаемых с литературными
результатами при явно сопоставленных геометрии, материальных данных, ширинах
линий, определениях дипольного момента и нормировках поля.
